# Frequency

Standalone Frequency cartridge. Requires Cartridge 0.6.0 or newer.

- Install `dev.cartridge.frequency.tar.gz`; its files are at the archive root.
- `SHA256SUMS` verifies the package and `release.json`.
- `release.json` contains pinned package metadata for the Cartridge Store.
- Runtime permissions: network, audio, storage.

See the repository README for controls, attribution, development, and runtime integration checks.
